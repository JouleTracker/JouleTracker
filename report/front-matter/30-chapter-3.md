## 3.1. User Stories

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
|---|---|---|---|---|
| **US-01** | Registro de usuario | **Como visitante**, quiero registrarme en JouleTracker proporcionando mis datos personales y credenciales, para poder acceder a las funcionalidades de monitoreo de consumo eléctrico. | **Escenario 1: Registro exitoso**<br><br>**Dado** que el visitante no posee una cuenta registrada<br>**Cuando** completa los campos obligatorios con información válida<br>**Entonces** el sistema crea la cuenta correctamente<br>**Y** permite al usuario acceder a JouleTracker.<br><br>**Escenario 2: Correo electrónico ya registrado**<br><br>**Dado** que existe una cuenta asociada al correo proporcionado<br>**Cuando** el visitante intenta registrarse utilizando dicho correo<br>**Entonces** el sistema rechaza el registro<br>**Y** comunica que el correo ya se encuentra registrado.<br><br>**Escenario 3: Datos obligatorios incompletos**<br><br>**Dado** que el visitante se encuentra en el formulario de registro<br>**Cuando** intenta registrarse sin completar todos los campos obligatorios<br>**Entonces** el sistema no crea la cuenta<br>**Y** indica qué información debe completar. | **EP-01** |
| **US-02** | Inicio de sesión | **Como usuario registrado**, quiero iniciar sesión con mis credenciales, para acceder de forma segura a mi información de consumo eléctrico. | **Escenario 1: Inicio de sesión exitoso**<br><br>**Dado** que el usuario posee una cuenta activa<br>**Cuando** ingresa un correo y contraseña válidos<br>**Entonces** el sistema autentica al usuario<br>**Y** permite acceder al dashboard principal.<br><br>**Escenario 2: Contraseña incorrecta**<br><br>**Dado** que el correo pertenece a una cuenta registrada<br>**Cuando** el usuario proporciona una contraseña incorrecta<br>**Entonces** el sistema rechaza el acceso<br>**Y** comunica que las credenciales son incorrectas.<br><br>**Escenario 3: Cuenta inexistente**<br><br>**Dado** que el usuario se encuentra en la pantalla de inicio de sesión<br>**Cuando** proporciona un correo no registrado<br>**Entonces** el sistema no inicia sesión<br>**Y** comunica que no existe una cuenta asociada al correo. | **EP-01** |
| **US-03** | Recuperación de contraseña | **Como usuario registrado**, quiero recuperar el acceso a mi cuenta cuando olvide mi contraseña, para poder continuar utilizando JouleTracker. | **Escenario 1: Solicitud válida**<br><br>**Dado** que el usuario posee una cuenta registrada<br>**Cuando** solicita recuperar su contraseña utilizando su correo<br>**Entonces** el sistema inicia el proceso de recuperación<br>**Y** envía las instrucciones correspondientes.<br><br>**Escenario 2: Correo no registrado**<br><br>**Dado** que el usuario se encuentra en la recuperación de contraseña<br>**Cuando** ingresa un correo no asociado a ninguna cuenta<br>**Entonces** el sistema no inicia la recuperación<br>**Y** informa que el correo no está registrado.<br><br>**Escenario 3: Nueva contraseña válida**<br><br>**Dado** que el usuario accedió correctamente al proceso de recuperación<br>**Cuando** establece una nueva contraseña válida<br>**Entonces** el sistema actualiza sus credenciales<br>**Y** permite iniciar sesión con la nueva contraseña. | **EP-01** |
| **US-04** | Verificación de cuenta | **Como usuario recién registrado**, quiero verificar mi cuenta, para confirmar mis datos y habilitar el acceso completo a JouleTracker. | **Escenario 1: Verificación exitosa**<br><br>**Dado** que el usuario posee una cuenta pendiente de verificación<br>**Cuando** realiza correctamente el proceso de validación<br>**Entonces** el sistema marca la cuenta como verificada<br>**Y** habilita las funcionalidades correspondientes.<br><br>**Escenario 2: Verificación inválida**<br><br>**Dado** que el usuario intenta validar su cuenta<br>**Cuando** utiliza información de verificación inválida<br>**Entonces** el sistema rechaza la verificación<br>**Y** solicita realizar nuevamente el proceso.<br><br>**Escenario 3: Cuenta previamente verificada**<br><br>**Dado** que la cuenta ya fue verificada<br>**Cuando** el usuario intenta repetir el proceso<br>**Entonces** el sistema mantiene el estado de la cuenta<br>**Y** comunica que la verificación ya fue realizada. | **EP-01** |
| **US-05** | Cierre de sesión | **Como usuario autenticado**, quiero cerrar mi sesión, para evitar que otras personas accedan a mi información de consumo desde el mismo dispositivo. | **Escenario 1: Cierre exitoso**<br><br>**Dado** que el usuario mantiene una sesión activa<br>**Cuando** selecciona la opción de cerrar sesión<br>**Entonces** el sistema finaliza la sesión<br>**Y** redirige al usuario a la pantalla de acceso.<br><br>**Escenario 2: Acceso posterior al cierre**<br><br>**Dado** que la sesión fue finalizada<br>**Cuando** el usuario intenta acceder a una funcionalidad restringida<br>**Entonces** el sistema bloquea el acceso<br>**Y** solicita iniciar sesión nuevamente.<br><br>**Escenario 3: Sesión expirada**<br><br>**Dado** que la sesión del usuario ha expirado<br>**Cuando** intenta realizar una operación protegida<br>**Entonces** el sistema impide continuar<br>**Y** solicita nuevamente sus credenciales. | **EP-01** |
| **US-06** | Registro de sensor IoT | **Como usuario registrado**, quiero registrar un sensor IoT en JouleTracker, para comenzar a monitorear el consumo eléctrico de mi hogar o negocio. | **Escenario 1: Sensor registrado correctamente**<br><br>**Dado** que el usuario posee un sensor compatible<br>**Cuando** proporciona un identificador válido del dispositivo<br>**Entonces** el sistema registra el sensor<br>**Y** lo asocia con la cuenta del usuario.<br><br>**Escenario 2: Sensor ya registrado**<br><br>**Dado** que el sensor ya está asociado a una cuenta<br>**Cuando** el usuario intenta registrarlo nuevamente<br>**Entonces** el sistema rechaza la operación<br>**Y** informa que el dispositivo ya se encuentra registrado.<br><br>**Escenario 3: Identificador inválido**<br><br>**Dado** que el usuario está registrando un sensor<br>**Cuando** proporciona un identificador incorrecto<br>**Entonces** el sistema no registra el dispositivo<br>**Y** solicita verificar la información. | **EP-02** |
| **US-07** | Asignación de nombre al sensor | **Como usuario registrado**, quiero asignar un nombre a cada sensor, para identificar fácilmente el dispositivo que estoy monitoreando. | **Escenario 1: Nombre asignado correctamente**<br><br>**Dado** que existe un sensor registrado<br>**Cuando** el usuario proporciona un nombre válido<br>**Entonces** el sistema guarda el nombre<br>**Y** lo muestra junto al dispositivo.<br><br>**Escenario 2: Nombre vacío**<br><br>**Dado** que el usuario está configurando el sensor<br>**Cuando** intenta guardar un nombre vacío<br>**Entonces** el sistema impide completar la operación<br>**Y** solicita ingresar un nombre válido.<br><br>**Escenario 3: Cambio de nombre**<br><br>**Dado** que el sensor posee un nombre asignado<br>**Cuando** el usuario lo modifica<br>**Entonces** el sistema actualiza la información<br>**Y** muestra el nuevo nombre. | **EP-02** |
| **US-08** | Asignación de ubicación al sensor | **Como usuario registrado**, quiero indicar la ubicación donde se encuentra instalado un sensor, para saber qué zona de mi hogar o negocio está siendo monitoreada. | **Escenario 1: Ubicación registrada**<br><br>**Dado** que el sensor se encuentra asociado a la cuenta<br>**Cuando** el usuario selecciona una ubicación válida<br>**Entonces** el sistema guarda la ubicación<br>**Y** la relaciona con el dispositivo.<br><br>**Escenario 2: Cambio de ubicación**<br><br>**Dado** que el sensor fue trasladado a otra zona<br>**Cuando** el usuario modifica su ubicación<br>**Entonces** el sistema actualiza la información correctamente.<br><br>**Escenario 3: Ubicación no especificada**<br><br>**Dado** que el usuario no proporciona una ubicación<br>**Cuando** consulta la información del sensor<br>**Entonces** el sistema muestra el dispositivo sin ubicación asignada<br>**Y** permite configurarla posteriormente. | **EP-02** |
| **US-09** | Consulta del estado del sensor | **Como usuario registrado**, quiero consultar el estado de conexión de mis sensores, para comprobar si están enviando información correctamente. | **Escenario 1: Sensor conectado**<br><br>**Dado** que el sensor está enviando datos correctamente<br>**Cuando** el usuario consulta sus dispositivos<br>**Entonces** el sistema muestra el sensor como conectado.<br><br>**Escenario 2: Sensor desconectado**<br><br>**Dado** que el sensor dejó de enviar información<br>**Cuando** el usuario consulta su estado<br>**Entonces** el sistema lo muestra como desconectado<br>**Y** señala la última comunicación registrada.<br><br>**Escenario 3: Actualización del estado**<br><br>**Dado** que un sensor recupera la conexión<br>**Cuando** vuelve a enviar información<br>**Entonces** el sistema actualiza su estado<br>**Y** lo muestra nuevamente como conectado. | **EP-02** |
| **US-10** | Desvinculación de sensor | **Como usuario registrado**, quiero desvincular un sensor de mi cuenta, para dejar de monitorear un dispositivo que ya no utilizo. | **Escenario 1: Desvinculación exitosa**<br><br>**Dado** que el sensor pertenece a la cuenta del usuario<br>**Cuando** solicita eliminar su asociación<br>**Entonces** el sistema desvincula el sensor<br>**Y** deja de mostrarlo entre sus dispositivos activos.<br><br>**Escenario 2: Confirmación requerida**<br><br>**Dado** que el usuario selecciona la opción de desvincular<br>**Cuando** todavía no confirma la operación<br>**Entonces** el sistema mantiene el sensor registrado<br>**Y** solicita confirmación antes de continuar.<br><br>**Escenario 3: Sensor inexistente**<br><br>**Dado** que el sensor ya no se encuentra asociado a la cuenta<br>**Cuando** el usuario intenta desvincularlo nuevamente<br>**Entonces** el sistema informa que el dispositivo no está disponible. | **EP-02** |
